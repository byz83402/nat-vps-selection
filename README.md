## NAT VPS 便宜在哪，代价又在哪

一个独享公网 IPv4 的采购成本，有时候能顶上一台低配 VPS 的全部售价。商家把这样一个 IP 切成十几份，每份给你 20 个端口做转发，再配一段 IPv6，价格立刻掉到年付几美元的量级。NAT（Network Address Translation）做的就是这件事：把公网地址翻译成私网地址，靠 port forwarding 让外面的人能访问到你机器上的某个服务。从规格上看，NAT VPS 和普通 VPS 没有本质区别，CPU、内存、硬盘、系统都一样，唯一的差别是那个公网 IP 不属于你一个人。

这个“唯一差别”会带来两个具体后果。

**IPv4 侧你只能用商家分配的那 20 个高位端口**，比如 7788、52402 这种，不能自己监听 80 和 443。想跑 web 服务，要么让访客带着端口号访问，要么用 Cloudflare 在前面挡一层做端口转换（后面会讲这套怎么搭）。

**IPv6 侧通常是完整的**，一般给一个 /64 段，全端口开放，可以直接用 `[IPv6地址]:80` 访问。这是 NAT VPS 真正的价值所在：花几美元拿到一段可以随便用的公网地址空间。

判断一台 NAT 小鸡值不值，第一条就是看 IPv6 给得够不够。少于一个 /64 的，在纯 v6 场景下基本没法用——你连给容器分地址的余量都没有。

20 个端口这个数字听着紧张，实际够不够取决于你干什么：SSH 占 1 个，一个 web 服务占 1 个，一个代理占 1 个，剩下十几个是给以后留的余量。真正容易出问题的不是数量，而是端口号是否固定——如果商家给你的是随机变动的端口，每次重启都换一个，那你的服务地址就得跟着改，这才是灾难。

## 下单前必须核对的六件事

下面的六条不是“NAT VPS 的通病”，而是你必须去商家官网或工单里逐条确认的条款。不同商家在这六条上的答案差别很大，答案不同，踩坑的后果也不同。

**线路是不是分档卖的。** 同样标着“新加坡 NAT”，走大陆优化线路和走普通国际 BGP，价格能差一倍，晚高峰的体验也差一倍。商家官网有没有明确区分“大陆优化”和“标准线路”，本身就是透明度指标。如果只写“新加坡机房”四个字什么都不说，默认按标准线路预期。

**IPv6 段给多大。** 至少要 /64。/80 能用但很紧，/48 属于商家很大方。这一条问清楚的原因是：你后面所有“不占端口”的服务都得靠 v6 撑。

**20 个端口是不是固定段。** 问清楚开通后给的是不是一段连续固定的端口，面板里能不能自己改映射。随机端口意味着你的服务对外地址不可预测，做中转和建站都会很痛苦。

**虚拟化是 KVM 还是 LXC。** KVM 隔离性好，能装自定义系统镜像，代价是资源开销大；LXC 轻量，同价位内存常常翻倍，但内核共享，需要加载内核模块的应用（某些 VPN、某些文件系统）跑不起来。跑代理和挂机选 LXC 划算，建站或要装特殊服务选 KVM 稳。

**退款政策。** 特价位置经常明写不支持退款。下单前先用商家提供的 Looking Glass 测一遍你所在运营商到机房的延迟和丢包，比看任何测评都准。

**商家级限制条款。** 这四条必须一条条看官网原文：IPv4 是否被默认屏蔽、只留 IPv6 可用（有些商家确实这么干，官网会写“IPv4 is blocked by GFW by defaults”）；流量超限后是直接断网还是限速、限到多少；下单后能不能更换机房地区；IPv6 的地理位置是否保证。任何一条没确认就付款，都是在赌。

这六条核完，你基本能判断自己能不能接受 NAT 这套约束。接受不了，往下看。

## 买回来之后：端口映射、IPv6 与几个高频卡点

**端口映射到底长什么样。** 在 NAT 机型上，控制面板或开通邮件里会给你一张表，形如“外网 22001 → 内网 22、外网 22002 → 内网 80”。你要做的是把服务监听在内网端口上，然后用 `共享IP:外网端口` 访问。SSH 不是直接 `ssh root@IP`，而是 `ssh -p 22001 root@共享IP`。很多人第一次买 NAT 卡在这里，以为是机器没起来，其实是没带端口。

**IPv6 连接的前提。** 本地网络得先有 IPv6：家宽开了 v6、手机蜂窝有 v6、或者用一个双栈的中转机跳过去。三条都不满足，就只能走 IPv4 那 20 个端口。连上以后，v6 侧是全端口开放的，服务可以直接绑 `[你的v6地址]:80`，不用做任何映射。防火墙记得单独放行 v6，很多系统默认 v6 规则和 v4 是两套。

**用 Cloudflare 把非标端口变成标准端口。** 思路是让 CF 回源到你的高位端口，访客看到的仍然是 443。限制在于 Cloudflare 只代理一小串固定的非标端口：HTTP 侧是 8080、8880、2052、2082、2086、2095，HTTPS 侧是 8443、2053、2083、2087、2096。你分到的端口不在这串里，这套方案就走不通，这也是前面强调“端口要问清楚是否固定、具体是多少”的原因之一。

**代理怎么搭。** 在机器上跑 dante、3proxy 或者 x-ui 这类工具，把 SOCKS5 或 HTTP 代理监听在某个端口上，NAT 机型通过端口转发暴露到公网，独立 IP 机型直接对外。浏览器、手机、模拟器走这个出口，就是一套成本远低于住宅代理的落地方案。注意代理端口暴露在公网一定要加认证，不然几小时内就会被扫到并滥用。

**流量要盯着。** 用 vnstat 或者面板自带的流量图，别等被限速了才发现。NAT 商家常见的规则是超量后把端口限速到很低，机器不断网但基本没法用；独立 IP 套餐超量后的处理方式各家不同，买之前问清楚。

## 限制与不适合的人

NAT VPS 最大的硬伤是端口，这一点无法绕过。所有依赖标准端口、依赖固定对外地址的业务，都不该放在 NAT 上。

第二个问题是邻居。共享 IP 段里只要有一个人发垃圾邮件、跑灰产，整段地址被 RBL 收录，你的邮件送不进、部分平台的风控也会连带降权。这不是商家能完全控制的事。所以 NAT 机器只适合跑非关键业务，正经项目上独立 IP。

第三，这类低价机型普遍没有 SLA。它的定位是“便宜、能用、随时可能出点小状况”，不是“保证 99.9% 在线”。商用站、需要 SMTP 发信的业务、对端口完整性有强依赖的服务，三条里中一条就别选 NAT。

丽萨主机这批新加坡套餐也有它自己的限制，得说清楚：网络是国际 BGP，不是大陆直连优化，官方建议经香港或日本中转，这意味着你大概率还要再配一台中转机，那是额外成本；不限流量两档的带宽分别是 200Mbps 和 500Mbps，比按流量计费的豪华版（1000Mbps）低；新加坡机房对国内三网的实际体验，联通和部分地区移动直连尚可，电信用户建议老老实实走中转。

## 常见问题

**NAT VPS 能建站吗？** 技术上能，用 Cloudflare 回源把非标端口映射成 443，访客看到的是正常域名。但你的源站端口必须在 CF 支持的那串列表里，且共享 IP 被牵连的风险一直存在。真要建站，独立 IP 是更省心的选择。

**IPv4 连不上怎么办？** 先确认本地是否有 IPv6。有些商家的 IPv4 默认被屏蔽、只留 v6 可用，这种情况只能走 v6 或加一台双栈中转。买之前把这条写进核对清单。

**20 个端口够用吗？** 对 SSH + 一个 web + 一个代理的组合绰绰有余。真正的风险不是数量，是端口是否固定。随机变动的端口段会让你的服务地址不可预测，这一条比数量重要。

**KVM 和 LXC 怎么选？** 跑代理、挂机、跑容器选 LXC，同价位内存更多；要装自定义系统、要加载内核模块、要建站选 KVM。拿不准就选 KVM，兼容性上限更高。

**独立 IP 比 NAT 贵多少？** NAT 小鸡的年付价格通常落在几十元人民币这个量级，独立 IP 的新加坡原生方案最低到 38.8 元/月。差价大概是每月一杯咖啡，换来的是不用做端口映射、能绑 80/443、IP 不被邻居牵连。这笔钱值不值，取决于你的用途踩没踩到那三条硬限制。
